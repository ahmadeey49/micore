# micore
Micore AI – Micro Credit Scoring System

Micore AI is an AI-powered micro credit scoring web application built to support financial inclusion for small businesses and underserved entrepreneurs.

The system uses machine learning to analyze financial data and estimate the creditworthiness of a loan applicant. It is designed as a prototype fintech solution that demonstrates how artificial intelligence can assist lenders in making faster and more informed loan decisions.

This project was developed as part of the 3MTT (Three Million Technical Talent) NextGen Knowledge Showcase.

Key Features

Micore AI includes several intelligent features that simulate a real fintech credit assessment system:

- AI Credit Scoring using a Random Forest machine learning model
- Loan eligibility prediction
- Credit score gauge visualization
- Bank statement analysis using PDF parsing
- Alternative data scoring for unbanked applicants
- Fraud detection alerts for suspicious financial patterns
- Smart loan amount recommendation
- Business growth prediction insights
- Financial overview charts
- Fintech analytics dashboard showing applicant statistics
- Applicant history tracking

These features help demonstrate how AI can support lending decisions while reducing credit risk.

How the System Works

1. The user enters financial information such as income, expenses, loan amount, and repayment duration.
2. The system calculates financial indicators such as expense ratio and repayment ratio.
3. A trained Random Forest machine learning model analyzes the data.
4. The application generates a credit score and predicts whether the applicant is eligible for credit.
5. The system provides recommendations and insights to improve financial eligibility.

Purpose of the Project

The goal of this project is to demonstrate how artificial intelligence can be used to improve credit accessibility for micro and small businesses, especially for individuals who may not have strong traditional banking records.

Micore AI shows how machine learning can support digital lending platforms and help expand financial inclusion.
